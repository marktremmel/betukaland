# Betűkaland · Typing Adventure

A browser typing adventure for grades 3 to 6 on Hungarian (QWERTZ) keyboards. Phaser 3, plain JavaScript, no build step for the code. Teacher notes: [TEACHER_NOTES.md](TEACHER_NOTES.md). Credits: [CREDITS.md](CREDITS.md).

## Play

Online: `https://<your-user>.github.io/<repo>/`. Offline: double-click `index.html`.

## Publish on GitHub Pages

1. Create a repository and upload this folder (everything, including `assets/` and `vendor/`).
2. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. After a minute the game is at the address GitHub shows.

Licences: several asset packs (Berie's Adventure, Crabby Beach, Helton Yan's SFX) allow use in your own games but forbid redistributing the raw files. A public repository lets anyone download those files directly. Safer: keep the repository private (GitHub Pages works from private repositories on GitHub Pro, Team or the free GitHub Education teacher benefits) or check each pack's licence first.

## Project layout

```
index.html, style.css     page and HTML overlays
src/config.js             regions, keys, fingers, stars, speed targets, shop
src/strings_hu.js         every child-facing text (Hungarian)
src/strings_en.js         the same in English
src/i18n.js               interface language switch, English names
assets/fonts/fonts.js     Andika, Atkinson Hyperlegible, Lexend (embedded, OFL)
src/wordbank.js           filters words by unlocked keys; phases; adaptive picks
src/adaptive.js           per-key accuracy and speed
src/save.js               localStorage profiles, save codes, save files
src/levelgen.js           procedural level assembly
src/encounters.js         walker, flyer, gate, bridge, chest, mini-boss, boss, shop, rest
src/keyboard_view.js      on-screen keyboard
src/typing.js             word bubble
src/scenes/*.js           boot, title, profiles, placement, map, level, results, overlays, teacher
data/words_*.js           word and sentence lists
assets/                   generated by tools/build_assets.py (never edit by hand)
tools/                    asset builder, offline pack builder, word bank report
```

Rebuild assets: `python3 tools/build_assets.py --lib "/Users/marktremmel/Downloads/Game Assets"` then `python3 tools/build_pack.py` (Pillow and ffmpeg needed).

To add a region: set `playable: true` in `src/config.js`, give it walkers, a mini-boss and a boss, and add sprites in `tools/build_assets.py`.
